**Period Range Parsing Rules:**
- DAY_PERIOD = Single slot (e.g., MON_1)
- DAY_X-DAY_Y = Range (e.g., MON_1-MON_3 = periods 1,2,3)
- Everyday_X = All weekdays (e.g., Everyday_4 = MON_4, TUE_4, WED_4, THU_4, FRI_4)
- Comma-separated = Multiple slots (e.g., TUE_2,THU_2)
- Days: MON, TUE, WED, THU, FRI

## Step 2: Process and Place All Pre-Placement Slots

**Goal:** Parse each row in the PREPLACE sheet, expand period ranges into individual slots, and place them in the timetables.

### Understanding Period Range Syntax:

The `periods` column in PREPLACE uses special notation that you must parse and expand:

**Format Rules:**
- `DAY_PERIOD` = Single slot (e.g., `MON_1` means Monday Period 1)
- `DAY_START-DAY_END` = Range on same day (e.g., `MON_1-MON_3` means Monday Periods 1, 2, 3)
- `Everyday_PERIOD` = Same period every weekday (e.g., `Everyday_4` means Period 4 on MON, TUE, WED, THU, FRI)
- Multiple ranges separated by commas (e.g., `TUE_2,THU_2` means Tuesday Period 2 AND Thursday Period 2)

**Days:** MON, TUE, WED, THU, FRI

**Your Task:** Parse these expressions into individual (day, period_label) pairs.

---

### Agent Workflow:

**Step 2a: Retrieve All PREPLACE Rows**

Get all rows to process:
```
Action: LoopProcessPreplaceSheet
Action Input: {"sheet_name": "PREPLACE", "start_index": 0}
```

**Step 2b: For Each Row, Parse and Place Slots**

For each row retrieved from PREPLACE:

1. **Extract Row Data:** Get the values for:
   - `class_id` (e.g., "1/1")
   - `subject_id` (e.g., "M10011")
   - `teacher_id` (e.g., "T001" or null)
   - `room_id` (e.g., "C104" or null)
   - `periods` (e.g., "MON_1-MON_3" or "Everyday_4")

2. **Parse the Period String:** Analyze the `periods` value and expand it into individual (day, period_label) pairs.

   **Example Parsing:**
   - Input: `"MON_1-MON_3"` → Output: `[("MON", "1"), ("MON", "2"), ("MON", "3")]`
   - Input: `"Everyday_4"` → Output: `[("MON", "4"), ("TUE", "4"), ("WED", "4"), ("THU", "4"), ("FRI", "4")]`
   - Input: `"TUE_2,THU_2"` → Output: `[("TUE", "2"), ("THU", "2")]`

3. **For Each (day, period_label) Pair:**

   a. Find the period column format using the period_label:
   ```
   Action: FindPeriodColumn
   Action Input: {"period_label": "1"}
   ```
   This returns the period_col in format `"label,time"` (e.g., `"1,07.55-08.05"`)

   b. Place the slot in the timetable:
   ```
   Action: PlaceScheduleSlot
   Action Input: {
     "day": "MON",
     "period_col": "1,07.55-08.05",
     "subject_id": "M10011",
     "teacher_id": "T001",
     "room_id": "C104",
     "class_id": "1/1",
     "reason": "preplace"
   }
   ```

4. **Monitor Responses:** If PlaceScheduleSlot returns a CONFLICT message, note it and continue with the next slot.

## Expected Data Structure

The PREPLACE sheet should contain columns:
- `class_id`: Student class identifier (e.g., "1/1", "2/3")
- `subject_id`: Subject/activity code (e.g., "M10011", "FREE")
- `teacher_id`: Teacher identifier (e.g., "T001", "E005") - may be null/empty
- `room_id`: Room identifier (e.g., "C104", "B108-109") - may be null/empty
- `periods`: Period range expression (e.g., "MON_1-MON_3", "Everyday_4", "TUE_2,THU_2")
